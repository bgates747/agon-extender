# NET-001 — Replace the active browser-video viewer on a new connection

## Executive summary

The Author authorizes the P4 to accept a new video connection while another
viewer remains connected. Keep one active viewer: the newest successful
WebSocket handshake replaces the previous viewer. The displaced webpage can
stay open and reconnect explicitly. This task does not change audio, EMOS,
keyboard ownership, the graphics renderer or the EVF1 frame format.

## Evidence and contract

A direct capture while the Author's webpage was connected received close1013,
`video client busy`, and zero frames. The existing network adapter implements
that deliberate admission policy. This is a requested network-policy change,
not a stock VDP rendering adaptation.

1. P4 accepts the newly handshaken viewer and closes the previous connection
   with a clear replacement reason. There is still only one frame consumer and
   one outstanding credit. No multi-client broadcast or reconnect tug-of-war.
2. Release previous credit/frame ownership exactly once. A delayed old socket
   close or queued send must not disconnect, complete or consume the new
   viewer's work. Account for worker acquisition racing the HTTP task.
3. Existing browser must remain open after displacement and permit explicit
   Connect. Do not add automatic reconnect. No browser keyboard revival.
4. Preserve RX06 numeric repair and installed-parent provenance. Record new
   firmware identity and hashes; preserve rollback before flashing. Do not
   silently incorporate unrelated UART or diagnostic changes into this build.
5. Host tests cover idle, pending credit, queued frame, acquisition/takeover
   race and delayed old cleanup. Hardware test uses viewer A, connects B while
   A is active, reads valid frames on B, then explicitly reconnects A. Record
   close reasons and verify repeated replacement without firmware reset.
6. Human browser review remains required. Experimental firmware is not pushed
   before review. Preserve current game and startup; notify when ready.
