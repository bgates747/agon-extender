# R01-05 — Local installation candidate

## Executive summary

The corrected P4 build, exact-reproduced EMOS and SD MOSlet, pinned host clients,
operator guidance and source/notices are packaged as `extender-installation-r01`.
The runtime archive is 1,861,555 bytes; source/support is 464,654,947 bytes. Both
archives and a second retained copy pass integrity checks. This is an **unselected
draft**: no current installation changed, no public distribution was made, and
no hardware or emulator operation occurred. R01-06 local validation is next.

agents one place to find the [bundle record](../../../production/bundles/extender-installation-r01/bundle.yaml),

## Explicit limits and next gate

The archive is suitable for continued **local candidate review**, not automatic
installation. The guide addresses independent input bootstrap, broken mainboard
keyboard constraints, listener self-overwrite, clean service exit, FLASH automatic
reboot, prefix settings overwrite, backup placement and rollback. It never
assumes an unavailable input path can enable itself.

The corrected P4 binary leaves browser reset unavailable. Existing bench reset
capability must be deliberately preserved through a separately configured build
before a deployment that requires that feature; this package must not be silently
patched. Hardware compatibility/performance remains unproven. No FPS claim is made.

Licensing inspection retains project and third-party source/notices. The MOS
builder lacks a top-level license; the dependency snapshot also is not presented
as a complete public corresponding-source offer. [NOTICES](../../../production/NOTICES.md)
records these public-publication gates. Local assembly does not resolve them.

R01-06 should independently walk the packaged instructions and remaining local
matrix, including the configured-reset decision before any bench handoff. R01-07
still requires bench availability/authorization and Author acceptance; R01-08
alone may advance the current selection. R01-05 is complete within this boundary.
