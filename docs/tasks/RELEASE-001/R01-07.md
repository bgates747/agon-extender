## First deployment failure and bounded correction

r54 factory write and independent flash verification passed, but the P4 panicked
at bootloader entry (`0x4ffac2c0`, illegal instruction). Deployment failed. Its
fresh build's application configuration selects silicon revisions 100–199;
its bootloader configuration instead selects 301–399 and links rev3/ECO5 ROM
symbols. PlatformIO forwards the relative `pio/p4-console.sdkconfig` unchanged
to the bootloader's separate CMake directory. That path does not select the
application configuration there, allowing incompatible defaults.

Restore the exact incoming full-flash backup before further candidate testing.
The bounded correction resolves the selected configuration to an absolute path
in the maintained pre-build hook and rejects a build unless both generated
configuration headers select 100–199. r55 identifies that correction. No renderer,
protocol, compression, pacing or upstream source changes belong in this fix.
The frozen r01 bundle is retained as failed preparation evidence, not deployable
media; r52/r53 share the affected clean-build path. Replace only with a separately
identified package after successful corrected-build and hardware checks.
