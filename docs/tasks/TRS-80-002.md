## Boundaries

The browser kit presents generated final pixels; it is not a TRS-OS terminal
or emulator. The storage kit exercises production record framing, queueing,
retry and client-state behavior with synthetic peers; it does not implement a
filesystem server or TRS-NET. EMOS and the foreground `sdserve` application
remain dependencies of real mainboard-SD access, owned outside this repository.
The TRS-NET probe executes the hash-verified upstream Python server unchanged
with simulated serial input; no physical port is opened and no guest is booted.
The kits contain no firmware, guest disk images, fonts or copied upstream
TRS-OS/TRS-NET code. Reference repositories remain on Linux under the location
selected in TRS-80-001; the future owned TRS-80 project remains uncreated.
