# HOST-001 work directory

## Executive summary

This directory holds the bounded research, provisional tools and evidence for
the new Oryx Pro's proposed Linux Lite migration. The [task record](../HOST-001.md)
owns scope, actionable steps, decisions and validation; [TODO](../../../TODO.md)
indexes its unfinished work.

| Location | Purpose | Git handling |
|---|---|---|
| This directory | Sanitized research, provisional scripts and reviewed evidence added as work progresses | Tracked after review |
| `private/CONTEXT.md` | Machine distinction, exact conversation links and local checkpoint | Ignored |
| [Private history précis](private/PRECIS.md) | Reviewed 295-page conversation: attempts, failures, evidence limits and stopping point | Ignored |
| [Private preparation results](private/prep/PREPARATION.md) | Recovery bundle, exact ISO findings, staged helpers, aligned layout and migration settings | Ignored |
| [Private dual-boot plan](private/DUAL-BOOT-PLAN.md) | Accepted roughly equal 1 TB per-OS budget, proposed layout, preservation/live-control/resize/install gates | Ignored |
| [Running action/result log](private/RUNNING-LOG.md) | Chronological work and outcomes; append as work proceeds | Ignored |
| [Attached multiboot USB](private/inventory/USB.md) | Mounted USB identity, installer filenames/capacity and verification limits | Ignored |
| [Current SSH inventory](private/inventory/SUMMARY.md) | Hardware, software, partitions/encryption, graphics, boot, network and service snapshot with evidence links | Ignored |
| `private/exports/` | Original account export ZIPs, Author-supplied conversation PDFs and their hashes | Ignored |
| `private/extracts/` | Selected conversation text/HTML, metadata and attachments | Ignored |
| `private/inventory/` | Machine-specific hardware, storage, network and dependency records | Ignored |
| `private/receipts/` | Local preservation, installation and validation receipts | Ignored |

The private directory is a Git exclusion, not encryption or a backup. Store
credentials in the existing protected credential facilities. Retain original
export bytes; keep generated extracts distinguishable from sources. Review and
redact any material deliberately promoted into tracked research or evidence.

Shared host setup tools and accepted cross-project guidance belong in
`agon-dev-env`. This directory remains the investigation/review silo and does
not become a competing production host manual.
