# NET-006 — Console8 ESP8266 setup and BBS diagnostic utility

Build a reusable native C8 utility that reads private Wi-Fi settings from a
separate configuration file, joins using DHCP, and visibly checks the Pi BBS.
English progress, regular timeout breadcrumbs, Escape cancellation and redacted
logs make failures diagnosable without typing AT commands by hand. Public
redistribution is an eventual goal; the first package awaits manual C8 testing.

## Authority and boundaries

Smith directly requested this utility after the one moved-probe pinwalk, then
added visible BBS requests/replies and future public distribution. His existing
plan-first/commit/push workflow applies. This selects source, ordinary host
checks, a normal FIFO native compile and an identified manual package. It does
not authorize remote C8 access, firmware changes, reset, credential collection,
new async/OTIRX drivers, emulator execution or public release qualification.
The C8 eZ80 uses Radiotux's UART1 polling/1152008N1/no-flow-control pattern;
ESP8266 owns Wi-Fi/DHCP/TCP. MOS owns UART admission and normal VDP output.
Smith runs the package manually. Other owners keep their bench custody.

## Bounded research précis

1. Radiotux read-only `Agon-Software` baseline
   `e265db1de57c49142420324945c666049dc1ec53`,
   `ifconfig/src/ifconfig.c` and `minicom/src/terminal.c`: MOS UART1 open/close,
   nonblocking AgonDev receive, byte pacing, foreground polling and flowcontrol0.
   New configuration/error/timeout/BBS machinery is required; this is an
   attributed adaptation, not an unchanged-baseline pass. No upstream edit.
2. Official docs baseline `f9806bd3cbff6ed5d1c08bef1d51fed11764b86b`,
   `agon-docs/docs/mos/API.md` UART calls0x15–0x18. Official MOS v3.0.2
   `8336409351ee5314e02801a7b72a4f1bb5282519`, `src/uart.c`, read-only clean
   tagged baseline. AgonDev `agon/mos.h` defines clock units as centiseconds;
   do not inherit Radiotux's apparent millisecond interpretation.
3. [Espressif 2016 ESP8266 AT reference v1.5.4](https://www.espressif.com/sites/default/files/4a-esp8266_at_instruction_set_en_v1.5.4_0.pdf):
   `CWMODE_CUR`, `CWDHCP_CUR=1,1`, escaped `CWJAP_CUR`, `CIFSR`, single-link
   `CIPMUX=0`, `CIPMODE=0`, bounded `CIPSEND=n` prompt/SEND OK and length-delimited
   `+IPD`. Smith's actual photo reports AT1.3.0.0/SDK2.0.0. Reference support
   does not prove all commands work on that specimen; unsupported commands stop.
4. BBS consumer contract is the maintained `scripts/wifi_bbs.py`: bounded ASCII
   `help`, `time`, `uptime`, `quit` replies. Read complete length-delimited input,
   do not mistake `OK`/`ERROR` inside TCP data for modem command results.
5. Escape during an unfinished AT command or length-announced send must not
   inject cleanup commands into unknown command/data state. Close host UART,
   report the outstanding module state honestly; no reset or automatic replay.
6. Radiotux README permits free-software use/modify/redistribute without a
   precise named license. Retain attribution and upstream wording; resolve
   redistribution terms before a public release rather than invent a license.
