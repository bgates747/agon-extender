# Conditional physical invocation — owner receiver

A finite host receiver removes agent-turn delay between admitted peer readiness
and the single selected Agon RUN. The receiver does not change EMOS, P4, native
application bytes, normal startup or resource deadlines. It is experimental
source preparation until the exact sender/plan/arm configuration is frozen and
accepted by the two owners and the Pi resource owner.

1. `scripts/conditional_go.py` owns the reusable host gate. A fresh exclusive
   output directory is the one-arm journal. Existing GO or output refuses arm.
   It observes one selected marker for at most180 seconds with no target calls.
   The owner validator runs once after that marker; durable dispatch precedes
   the invocation callback. Exceptions, cancellation, expiry and host loss
   never restart the arm, select a successor or repeat the callback.
2. `scripts/bench_conditional_go.py` owns actual admission validation and the
   configured owner leaf invocation. The final local arm descriptor is supplied
   with its exact hash, after the executable plan is frozen. It selects the
   marker/output, request, native arguments/hash, actual bench identity,
   accepted-message evidence, immutable plan and source pins. Peer marker text
   cannot supply a command. An unexecutable preparation plan cannot arm it.
3. The adapter independently asserts actual Pi test and bench owners; checks all
   selected plan inputs and required invocation sources; binds original ready
   fields, controller/bridge PIDs and start identities to their live process,
   command and qualification unit; validates accepted canonical START and GO
   receipts against exact message bytes and endpoints; and checks the published
   durable GO body against all core marker fields. Retained loaded/graphics
   admission records must be pinned by the final plan.
4. Readiness carries the controller's actual original registration deadline,
   never ready-time plus90 seconds. Require at least15 seconds remaining after
   validation for command delivery, GO age at most10 seconds, a guard heartbeat
   at most3 seconds old and original whole-grant budget. A ready event can
   precede the guard's first producer sample; the receiver observes the same
   trace for at most2 seconds before refusing. This emits no target command,
   repeats no GO, restamps no evidence and extends no deadline.
5. `native_go` in the final plan selects `marker_path`, `guard_heartbeat_path`,
   `start_message_path`, `start_delivery_path`, `go_message_path` and
   `go_delivery_path`. The final local descriptor's `paths` copies those six
   values. Its `expected` binds schema/owner/request/plan path/hash/bench/ready
   path/native hash and arguments. `required_sources` must be identical to
   final-plan input pins. `loaded_receipt`, `graphics_receipt` and
   `graphics_expected` bind the owner's admitted preconditions.
6. The descriptor selects source-pinned host lease-helper argv, recipient thread
   identities, mailbox directory, fixed `invocation_argv`, invocation receipt
   and a fresh `go_record` consumed only by the Extender-owned leaf. Machine
   addresses, device identity and lease tokens remain in ignored local records.
   The final descriptor is created after plan freeze to avoid a hash cycle;
   its exact bytes/hash are then retained in the arm handoff.
7. The owner invokes `.venv/bin/python scripts/bench_conditional_go.py --arm
   OWNER_DESCRIPTOR --arm-sha256 EXACT_HASH` only after the separate explicit
   conditional-GO disposition and source/readiness reconciliation. Do not run
   an example descriptor or arm during source checking. No competing manual
   RUN is allowed while armed. The adapter refuses root target access.
8. After validated dispatch the source-selected existing leaf alone opens the
   passive reader and issues the exact one RUN. That leaf has its own bounded
   observation/collection; the adapter bounds it to280 seconds. Cancellation or
   timeout stops/joins the owned host child, not the Agon application. Resulting
   target state requires owner evidence/recovery; a stopped host is not an idle
   bench. No reset or automatic replay occurs. Existing post-getter/mode0/CLI
   restoration and separate Pi cleanup/release/END retain their owners.
9. Host checks execute the real gate/validator using temporary files and injected
   resource observers. They qualify neither an armed handshake nor gameplay.
   They do not reserve, grant, start a real watcher/arena or access a board.
   Receiver journals are individually bounded; normal gate receipts total at
   most40KiB. The selected invocation log/result files retain their separately
   declared bounds. Staging, arming, dispatch, native completion and clean
   handback remain distinct facts.
