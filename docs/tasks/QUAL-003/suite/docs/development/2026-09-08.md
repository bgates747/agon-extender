## Inherited implementation findings

The shared `pingo_terrain/scripts/audit_adl_width.py` audit was run over the
16 application/import include files. It returned nonzero: 187 wide memory
accesses, including 67 accesses across declared byte/word boundaries and 23
indirect or unresolved review items. The remaining 97 accesses resolve to
24-bit or reserved storage. Its local report is
`build/adl-width-audit.txt`. These counts are mechanical classifications,
not 67 independently confirmed functional defects: the imported packet
builders frequently use adjacent padding or repair overwritten bytes.

Concrete boundaries found during inspection:

1. The new application has no wide memory loads/stores. Its string-output
   path does not execute the imported packet-building or timer routines.
2. Many VDU packet writes use a 24-bit store into a two-byte field, followed
   by repairing the next byte or absorbing it in unsent padding. They retain
   the source's behavior and comments; the snapshot has not been rewritten
   to the current exact-width assembly convention.
3. `vdu_font_property` stores DE to its final `@value` word without trailing
   padding. `vdu_font_copy_system` similarly stores HL to its final
   `@bufferId` word. In this combined build, each can overwrite the first
   byte of the following routine. Neither is called by Hello World.
4. `vdu_load_buffer_from_file` retains the fixed `0xB7E000` scratch address
   and does not check a zero file handle before starting reads.
5. The buffered API includes several `ret` placeholders. Inclusion is not
   evidence that every command in the Extender VDU inventory has a wrapper.
6. `timer.inc` includes direct timer and interrupt-vector manipulation.
   Those routines are dormant in this application and are not an EMOS
   integration interface. Its historical timing comments are not a newly
   verified timing contract.

The unchanged snapshot preserves provenance for this compilation task.
These observations bound the current result; implementation changes to
exercise additional routines belong to subsequent explicitly scoped demos.
