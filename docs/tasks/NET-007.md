# NET-007 — Quiet Console8 Wi-Fi startup utility

Provide a small Connect-or-Skip application for normal Console8 startup. The
ESP8266 joins the private configured wireless network using DHCP; the program
reports progress and the acquired address without running the BBS diagnostic.
It waits for a choice unless the private configuration explicitly enables
automatic connection. Detailed redacted logs remain available for faults.

## Authority and scope

Smith requested this task before implementation on2026-11-06, following UART
application-driver delegation. His subsequent instruction keeps our source
separate from Radiotux's and prefers unchanged reusable upstream files. Source,
ordinary bounded host checks and a normal FIFO native build/manual package are
selected. No C8 invocation/card deployment, firmware, startup-script, emulator
or occupied Olimex operation is selected. The accepted setup/BBS package remains
available unchanged; this utility is a separate application.

## Research précis

1. Reuse [NET-006](NET-006.md)'s exact local read-only MOS docs/source baseline,
   counted file I/O,120/100 clock conversion, bounded redaction and reply-before-
   output rule. Re-read official `agon-docs/docs/mos/API.md` before new API use.
2. Radiotux Agon-Software `e265db1de57c49142420324945c666049dc1ec53`,
   `ifconfig/src/ifconfig.c` and `ping/src/ping.c`, read-only: each defines its
   own main/send/wait/parser. His ping utility probes TCP ports and labels MOS
   counts as milliseconds; do not inherit those as actual ICMP measurements.
   No upstream source modification or unnecessary vendoring is required.
3. [Espressif AT reference v1.5.4, p64](https://www.espressif.com/sites/default/files/4a-esp8266_at_instruction_set_en_v1.5.4_0.pdf)
   defines `AT+PING="host"`, response `+<time>` then `OK`, or `ERROR` for
   failure. Modern `+PING:` response is not evidence of installed2016 support.
   Query current gateway only; do not infer address by replacing an IP octet.
4. Installed AT1.3.0.0/SDK2.0.0 and existing setup acceptance do not establish
   physical ping support. Explicit warnings and manual review retain that gate.

## Source and host checkpoint

Plan b3e18147 was pushed before implementation. The separate startup entry
point reuses only project-owned support from `tools/wifi-setup`; Radiotux
`e265db1` remains unchanged. No upstream driver module can be directly included
without importing its complete blocking application. This is an explicit
exception to direct inclusion, with no upstream modification or vendor patch.

`scripts/check_wifi_start.py`: existing24 AT scenarios/11 cancellation phases,
new startup gateway/two-ping/refusal/malformed/timeout/host/disabled cases,
startup cancellation at nine command phases, configuration compatibility and
nine startup file/menu/admission cases. A successful adapter case deliberately
refuses UART admission; no physical success is inferred. The initial native
development link passes. Host-model results do not qualify actual2016 ping
support, keyboard responsiveness or card logging on C8.
