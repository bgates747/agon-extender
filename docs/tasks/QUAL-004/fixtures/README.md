# Frozen graphics scenes

## Executive summary

These74 prepared command streams and matching resource-barrier sidecars are test inputs, not a declaration that74 scenes passed. Decompress the `.gz` files without changing bytes. The player loads a scene and its adjacent `.bar` file. Select the scene's recorded mode in startup first (mode20 for the original corpus). `SCENES.json` contains raw hashes and provenance; results live in the parent task. No production game assets or firmware are replaced by this package.
