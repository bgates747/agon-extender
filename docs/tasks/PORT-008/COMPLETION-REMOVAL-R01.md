# PORT-008 — Remove the software completion exchange, r01

## Executive summary

Author authorizes the next bounded implementation tranche after CRC removal,
with fsim using the bench. EMOS and P4 finish successful blocks at their existing
native-completion, DMA-cleanup and reciprocal UART-return boundary. Remove the
subsequent COMPLETE/ACK exchange and its wait state. Keep the actual electrical
handshake, buffer ownership and failure fence. Build and test offline only; no
device access, SD deployment, flash, reset or production change.

1. Parent [PORT-008](../PORT-008.md), P08-P05/D02/D03 in
   [PHASE-TIMING-R01](PHASE-TIMING-R01.md), and MT05/second code cut in the
   [minimum-transport review](MINIMAL-TRANSPORT-RESULTS.md). The broad eight-hour
   goal stays paused. Baselines: Extender eebd8ec9 and EMOS 051ddb7; both clean.
2. Official read-only references remain agon-docs
   f9806bd3cbff6ed5d1c08bef1d51fed11764b86b,
   [MOS RST10/RST18 contract](../../../../../agon-docs/docs/mos/API.md), and
   [VDP serial packets](../../../../../agon-docs/docs/vdp/System-Commands.md);
   clean MOS v3.0.2 and VDP v2.16.0. No application API, packet, parser,
   interrupt, rendering or video mode change belongs to this cut.
3. EMOS `emos_parallel_coordinator.c` currently reaches EPH_LIVE only after
   the native runner, pad release, local UART restore and fresh peer READY-high.
   P4 `p4_block_coordinator.cpp` reaches UART only after exact native completion,
   cleanup and EMOS's fresh return request/UART-up acknowledgement. These facts,
   rather than a second serial receipt, govern publication. A timer never
   establishes successful delivery.
4. P4 must validate local completion before advertising final READY-high, keep
   its completed descriptor/buffer until the sole consumer takes it, and retire
   that storage before accepting a later OFFER. Cancellation/fault clears the
   unpublished completion and retains cleanup ownership. A READY write failure
   must not leave a consumable result. EMOS releases its reservation only after
   the successful physical return; late local failures still fence the owner.
5. Select the next existing experimental wire discriminator, **4**, for the
   changed completion semantics. Format2/3 peers cannot admit this pair. Keep
   the sixteen-byte padded CRC-free carrier and remaining offers/session/control
   fields for this cut; do not add negotiation, checksums or retransmission.
   This is paired development compatibility, not a new production version/tag.
6. Ordinary version1 ExCom/SD behavior, GPIO/DMA timing, queue sizes, full/residual
   batching, VBlank scheduling, callback context and IRQ-disabled refusal remain
   unchanged. Their existing limits prevent any full stock-equivalence claim.
   No automatic retry/replay or endpoint-wide atomic-commit guarantee is added.
