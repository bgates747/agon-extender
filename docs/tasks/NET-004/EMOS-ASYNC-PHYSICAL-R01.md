# Provisional UART1 consumer trial — owner installation plan

Extender will install only the checked optional EMOS application-hook build for
MechAgon's separately frozen provisional trial. The existing P4, mainboard VDP,
startup and listener stay in place. This plan prepares that owner phase while
another consumer holds the bench; it makes no physical readiness claim.

## Selection and boundaries

1. Use the checked SDK revision and retained owner ROM/map in the ignored
   consumer binding. The current offline result is in
   [EMOS-ASYNC-R01-RESULT.md](EMOS-ASYNC-R01-RESULT.md). Preserve superseded
   bindings and failed consumer evidence rather than rebuilding firmware.
2. MechAgon owns its caller adaptation, actual linked size, callback chain,
   source/tail/reply regression checks, finite trial and normal reservation.
   Extender owns EMOS installation/readback and rollback. UART owns the generic
   application core. No vanilla IRQ installer replaces EMOS RX ownership.
3. Wait for the actual predecessor's clean handback. Obtain a fresh normal
   lease and request-bound context, input/CLI/idle observation and immutable kit.
   Extender must be the explicit sole operator for installation; a consumer
   grant alone does not authorize concurrent Extender commands.
4. Pin the owner helper and dependencies before admission. Check the selected
   ROM and full retained working rollback locally. Do not back up or reread
   unchanged firmware merely because another trial is starting. Refuse a
   different incoming component tuple until it is reconciled.

## Owner installation and verification

1. At a positively established Legacy CLI, check neutral input, idle worker,
   free serial ports, raw mode/callback/backend, setup-only startup and the
   canonical listener. The installed component identities and original native
   full-span restoration come from the actual predecessor's verified handback.
2. Stage both exact padded ROMs and independent verification command files
   under fresh request-owned `/extender/install` and `/agents/extender/results`
   paths. Read staged files back and compare every byte before FLASH. Preserve
   unknown files; no startup or canonical listener modification is permitted.
3. Stop the listener through acknowledged EXIT. Open the maintained passive
   serial reader, enable the existing printer mirror, and observe a unique
   sentinel before trusting boot output. Issue exactly one explicit
   `FLASH mos <selected-path> -f` command. Observe its automatic reboot and exact
   selected build identity. Missing/uncertain delivery or identity stops this
   phase without reset or FLASH replay.
4. From the new admitted CLI, explicitly execute the staged SAVE-only command
   file. It saves all 131072 ROM bytes, raw mode, callback and backend state,
   then starts the existing listener for collection. Compare the newly written
   full ROM independently, including padding. Check the unchanged startup and
   listener again; acknowledged EXIT returns the CLI. Installation includes no
   application LOAD/RUN, rendering smoke, generic echo or additional test.
5. Record the actual installed identity and fresh CLI/input/idle/free-port
   evidence. Stop all owner readers and commands before publishing a matching
   stopped handoff to MechAgon. The same lease remains exclusively owned during
   the consumer phase; Extender cannot observe hardware alongside it.

## Consumer return and rollback

1. After the finite trial, MechAgon joins every owned child and returns an
   explicit stopped handoff. Preserve failed application RAM before any LOAD
   and retain original transaction journals. Unknown CLI or a pending operation
   is a recovery boundary, not permission to inject rollback commands blindly.
2. Recover only through the maintained monitored recovery order if needed;
   reset is separate from test invocation. Do not replay the consumer trial or
   an uncertain transfer. P4 reset for recovery does not authorize P4 flashing.
3. At an established CLI, restore only the selected exact incoming EMOS ROM
   with the same stage/one-FLASH/full-readback protocol. The working P4 and
   mainboard application/tail remain unchanged. Compare the full restored ROM,
   raw state, whole startup/listener and fresh command/input/idle handback.
4. Record first faults, owner/consumer start and end times, hashes, explicit
   omissions and restoration proof. Join every reader/child, leave SD mounted,
   release normally and immediately notify the actual successor. No implicit
   watch, second trial, firmware promotion or performance claim follows.

## State

Offline installation-helper preparation is authorized under the existing
provisional integration/trial selection. Actual consumer kit, request-bound
owner freeze and fresh admission remain prerequisites for hardware access.
