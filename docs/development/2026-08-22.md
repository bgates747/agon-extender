durable `docs/dependencies/` project boundary. Schema 2.0 now records exhaustive
immutable source manifests, normalized per-profile file and source-region
selection, observed-versus-declared build drift, reviewed dispositions, and

reviewed seam anchors intentionally defer exact implementation boundaries to
the corresponding port work.

Qualification covered all 5,164 source files and source-region fingerprints,
six accepted boundary proofs, ten regression tests, all regenerated SETUP-004
survey inputs, and two complete byte-identical pipeline runs. No real
tagged-release merge report was generated because only one independently

automated evidence rather than claiming a personal record-by-record audit.

## PORT-003 — Display backend Review Gate 1

Prepared the bounded evidence and design package for the P4 display backend
without changing production firmware or vendored source. Deterministic
artifacts project the accepted display boundary from the canonical dependency
graph and fingerprint the relevant official VDP/vdp-gl sources plus five
pinned ESP32-P4 framework headers. Two complete generation passes were
byte-identical and the task-local invariants passed.

The manual trace identified mode fallback, packed native pixels, palette and
Copper scanline behavior, software versus hardware sprite composition,
readback, queue/swap completion, and the directly accessed frame counter as
compatibility constraints. The proposal recommends one project-owned generic
bitmapped controller, sink-independent logical frame time, one central
presentation compositor, and non-blocking latest-generation output consumers.

The Author accepted all seven architectural choices by delegation, explicitly
authorizing the Agent to commit and push the package without personal diff
review and to continue into Phase A without another pre-start review. ADR-0015
and the current architecture now record the accepted controller, native-format,
logical-clock, frame lifecycle, compositor, consumer, and phased-qualification
decisions. The package defines deterministic host oracles, later P4
qualification, and explicit stop conditions. Review Gate 1 does not claim a P4
compile, hardware timing, rendered-pixel fidelity, or any output sink
implementation.
