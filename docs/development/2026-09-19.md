# Development log — 2026-09-19

## Browser encoding default

Author accepted RLE2 as the default for browser video output going forward.
Live client already requests `?rle2=1`; ADR-0021 and the canonical architecture
and wire contract now preserve that policy. No firmware, pacing or runtime
changes. Remaining codec qualification gates stay explicit.

## Composed-frame packing experiment

Author selected full P4 composition followed by lossless packing for browser
transport, superseding BENCH-005's native-plane proposal. Software sprites,
hardware sprite overlays and Copper remain P4 responsibilities. The task's
composed-packing/PLAN.md freezes the experiment and full non-50-Hz mode matrix.
EVP1 carries a frame-local RGB222 palette and1/2/4-bit indices; more than16 final
colours use existing RLE2/raw. RLE2's old512×384 eligibility ceiling is raised to
1024×768 for matched controls. No mainboard firmware or production game changes.
Candidate02 adds a proven lower-bound short circuit to avoid pointless palette
scans when RLE2 already wins. Hardware matrix is in progress; this is not release
or human acceptance. Exact firmware/fixture identities and limits live in the task.
