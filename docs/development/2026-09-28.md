## BUILD-001 — native pre-LCD boot repaired

The boot failure was a native-build configuration mismatch, not an LCD defect.
ESP-Hosted 2.12.12 declares `WHOLE_ARCHIVE`; native ESP-IDF correctly retained
its constructor, which started the unused remote-Wi-Fi SDIO transport before
`app_main` and failed its large DMA-capable pool allocation. The proven hybrid
link had omitted that otherwise-unreferenced constructor. Extender uses the P4
wired Ethernet interface and did not expose remote Wi-Fi behavior.

Branch `codex/build001-prelcd` commit
`eadc2925e436754f5b7e0beddf088b01ded504ba` explicitly disables
`ESP_WIFI_REMOTE_ENABLED` and `ESP_HOSTED_ENABLED`. Native graph validation and
the BUILD-001 host controls passed; the application fell from 1,721,632 to
1,491,072 bytes and its map contains neither the Hosted constructor nor
`sdio_mempool_create`.
