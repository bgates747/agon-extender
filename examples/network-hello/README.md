# Network hello-world demonstration

**Refresh required before deployment.** This experimental fixture is retained
source and historical evidence, not an installed utility or a current test recipe.

## Purpose and limits

Demonstrates replacing a finite executable through the foreground SD service and playing short mono unsigned 8-bit PCM clips through ordinary VDP sample commands. Command acknowledgements are separate from human visual/audio confirmation.

## Reuse prerequisite

The source and observer use `/extender/hello-seen.txt`; the observer also relies on the old startup backup at `/extender/before-hello.txt`. Refresh receipt/backup paths and the complete installer/service handover. Preserve active EXEC/autoexec files; never overwrite an open startup batch.

[DEMO-001 D01-EX01](../../docs/tasks/DEMO-001.md) owns the refresh. Use
[SD layout](../../docs/sd-layout.md), [current SD operation](../../docs/mainboard-sd.md)
and [bench constraints](../../docs/qualification/bench-constraints.md). Prepare
Legacy/input admission before remote commands; select video mode only in
`/autoexec.txt`. A refreshed run needs identified bytes, preserved earlier
receipts, an explicit terminal state and its own bounded validation contract.
