# Light 2 Extender solderless assembly r01

`light2-extender-solderless-assembly-r01` identifies the preserved first
prototype breadboard configuration. It implements `light2-harness-r01` and is
retained for the bounded forward-transport work and firmware already developed
against that circuit.

This record does not reinterpret the predecessor evidence as proof of the new
four-wire UART circuit. The r01 board must remain wired to its r01 definition
unless a later task explicitly retires or revises it.

The exact current specimen identity and bench state remain machine-local. The
tracked design and inherited construction evidence live under
`hardware/designs/light2-harness-r01/`.
