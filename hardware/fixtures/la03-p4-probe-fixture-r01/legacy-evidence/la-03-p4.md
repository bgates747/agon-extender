# LA-03 — P4 endpoint capture

This diagnostic probes the P4 header pins directly after LA-02 proved that the
Agon poll crosses U1 channel 4 to U1 pin 11.

Keep the even-channel ribbon on EXT2 pins 10–13 and the odd-channel ribbon on
EXT1 pins 13–16. Attach each ribbon in order without crossing sides:

## Even ribbon — EXT2 first

| Logic channel | P4 probe point |
|---|---|
| D0 (green) | GPIO32 / EXT2 pin 10 (parallel D4 reference) |
| D2 (blue) | GPIO22 / EXT2 pin 11 (UART RX / D0) |
| D4 (purple) | GPIO21 / EXT2 pin 12 (`REV_OE_N`) |
| D6 (gray) | GPIO20 / EXT2 pin 13 (`READY_N`) |

## Odd ribbon — EXT1 second

| Logic channel | P4 probe point |
|---|---|
| D1 (yellow) | GPIO12 / EXT1 pin 13 (UART TX / D1) |
| D3 (orange) | GPIO13 / EXT1 pin 14 (`VALID_N`) |
| D5 (red) | GPIO14 / EXT1 pin 15 (`CLOCK`) |
| D7 (brown) | GPIO15 / EXT1 pin 16 (`FWD_OE_N`) |

Connect the black ground lead to a qualified P4 ground. Verify EXT1 versus EXT2
and each printed header pin number before power. Do not move probes while either
system is powered.
